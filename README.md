# agentic-planning-surface
A project dedicated to only planning for my opensource agentic projects

## Git autosync

This project is automatically synced to git. Any change it uploaded at maximum after 10s. A bit like Obsidian-git does.

It is meant to be messy and work like DropBox or Google Drive, but on git.

Agent should be automatically started a background shell on this folder when in a session. If not, just say "start autosync" to your agent.
