Agentic Surface project needs a automated git commit/fetch/rebase with an efficient and data-loss free conflict resolution.

An "Agentic Surface Project" is basically a project with what WILL change in one or several projects. It acts as a mid-long term planning "blackboard", with error, draft.

It is a blackboard between human and its agent, and human should be able to review.
Multiple user (<10p) is also planned.

autosync = like obsidian, where each change is pushed to git
after a while (10 seconds?) automatically.

Its structure will be strict. the auto-sync may be aware of the internal structure, but it should mainly focus on synchronizing git (and git lfs) efficiently.
