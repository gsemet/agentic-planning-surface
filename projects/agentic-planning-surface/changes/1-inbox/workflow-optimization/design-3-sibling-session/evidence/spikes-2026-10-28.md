# Spikes of 2026-10-28: a Foreman in its own VS Code tab

Three short runs on 2026-10-28, from 14:38 to 15:02, on Claude Code 2.1.310 in the VS Code
extension, macOS, subscription sign-in.

- **Chief of Staff:** a VS Code tab, Opus 5.5, auto mode.
- **Foreman:** a second VS Code tab, renamed `Handoff workflow-optimization [Foreman]` with
  `/rename`, Opus 5.5, auto mode.
- **Drivers and their children:** `general-purpose` subagents on Haiku 5.5, doing no real work.
  Their rounds are timed waits.

All messages went through cross-session `SendMessage`, addressed by session name. Times are local
(UTC+1). The transcripts are in `~/.claude/projects/-Users-az02065-Projects-Nestor-agentic-coding-white-paper/`,
session `70839404-ea06-4604-b1db-47993f779d77` and its `subagents/` folder.

then one `SendMessage` to the Foreman. A `CronCreate` job every 2 minutes sent the Chief of Staff
a status line.

## 4. What wakes the Foreman, and what it costs

Script: [scripts/triggers.py](scripts/triggers.py). Opus 5.5 prices; the Foreman's context grew
from 37k to 90k tokens over the two spikes.

| Trigger | Count | Foreman turns | Cost | Per trigger |
| --- | --- | --- | --- | --- |
| Driver message | 25 | 34 | $0.80 | $0.032 |
| Driver "waiting on its own background work" notice | 9 | 9 | $0.17 | $0.018 |
| Driver completion or stop | 9 | 7 | $0.20 | $0.022 |
| Cron tick, with a status message out | 4 | 12 | $0.20 | $0.050 |
| Chief of Staff message (orders, probes) | 7 | 26 | $0.98 | $0.141 |
| **Total, both spikes** | | **88** | **$2.34** | |

The "waiting" notice is new: each time a background Driver ends a turn while its own background
command still runs, its parent gets a notice and spends a turn. A Driver that re-arms a wait every
4.5 minutes therefore costs the Foreman one short turn per re-arm.

### 4.1 An agent file created mid-session (17:35)

The test agent file `.claude/agents/sim-driver.md` was written while the Foreman tab was open.
The Foreman's `Agent` tool did not list it, and a spawn with `subagent_type: "sim-driver"` failed:

> Agent type 'sim-driver' not found. Available agents: claude, claude-code-guide, Explore,
> general-purpose, Plan, statusline-setup

A session reads its agent files when it starts, not when it spawns. The cache test itself still
needs a Foreman tab opened after the file exists.

## 5. Not shown by these spikes

- Whether `TaskStop` on a Driver also stops its running foreground Coder.
- Whether the Foreman can message a Driver's Coder directly, by the Coder's agent ID.
- Whether a Driver agent file with `experimental.cacheTtl: 1h` gets 1-hour writes.
- A compaction of the Foreman, and a Foreman tab left idle for more than an hour.
- Real work: real Driver and Coder contexts are 3 to 5 times larger than in these runs.
