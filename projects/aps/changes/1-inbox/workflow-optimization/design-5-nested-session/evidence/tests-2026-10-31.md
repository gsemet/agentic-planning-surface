## 3. Lifecycle

| Check | Result |
| --- | --- |
| `TaskStop` on a waiting Driver | its background `sleep` and shell gone 5 s later (sim-1) |
| `TaskStop` on a Driver inside a foreground Coder round | the Coder's foreground `python3 … sleep(150)` call was interrupted at the stop ("Request interrupted"); no python process at +9 s and +44 s. The check before the stop used a `pgrep` pattern that cannot match, so kill is likely, not proven |
| `/loop` tick with `ScheduleWakeup` 90 s | rounded up to the next minute; fired +5 s late when the Foreman was idle, +52 s late when it was busy |
| 59-minute heartbeat | not reached: both runs landed before it |
| App notes to the Chief of Staff | one note at the end of every Foreman turn while the Foreman is linked; `detach_session` stops them |

- **Spike 1 of design 3 passes.** A Driver started from `.claude/agents/sim-driver.md` with
  `experimental.cacheTtl: 1h` writes only one-hour cache, and starts at 17–20k tokens instead of
  51–57k. The agent file is in [agents/sim-driver.md](agents/sim-driver.md).
- **The Desktop Foreman starts at 70k tokens,** against 37k in a VS Code tab: the app adds its own
  tools (sessions, browser, artifacts, view panes) to the main conversation.
- Haiku Drivers launched duplicate sleeps in 8 of 9 sim-2 runs and sometimes sent no time, so
  per-round timings are approximate.
